
# Relatorio de execução


## Evolução por nível

- **Básico**: Foi construido o fluxo principal da aplicação. A integração com a LLM
interação com o usuario por meio de linha de comandos.

- **Intermediário**: Foi feita validações da entrada do usuario, tratamento de erros e 
adição de testes unitarios. Algumas refatorações para utilizar configurações para os dois llms. 

- **Avançado**: Foi feita a integração com a LLM da Devel. E a refatoração para utilizar a LLM 
Gemini ou Devel com base na configuração do `.env`. Tambem foi adicionado uma aplicação WEB, além 
da aplicação de linha de comandos que já existia.
